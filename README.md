## Engineering approach

- **Evidence before claims:** tests, reproducible demos, provenance, and explicit limitations matter more than impressive-sounding features.
- **Local-first where it fits:** offline capability, SQLite/browser persistence, and graceful degradation before unnecessary backend complexity.
- **Bounded AI:** models assist with language-shaped or planning work while deterministic code owns critical state, calculations, permissions, and validation.
- **Small, inspectable systems:** prefer clear interfaces and boring infrastructure over speculative abstractions.
- **Ship the whole product:** UX states, security boundaries, documentation, release workflows, and verification are part of the implementation.
